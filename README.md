# SE Faculty & Academic Advisor Handbook

Public professional guidance for faculty and academic advisors of the
**B.Eng. Software Engineering** programme, School of Applied Digital Technology,
Mae Fah Luang University. Aligned to AUN-QA v4.0.

**No personal data** is stored here. All linked tools (forms, sheets, dashboards)
live inside the MFU Google Workspace / REG and require an MFU login.

Live site: published via GitHub Pages (`index.html`).
